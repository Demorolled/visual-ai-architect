# Hello Project

A production-ready Python application that demonstrates a layered architecture for a simple greeting system.

## Features
- Pydantic-based configuration management
- Layered architecture (Entry, Configuration, Logic)
- Clean separation of concerns

## Setup
1. Install dependencies: `pip install -r requirements.txt` (or use `poetry install`)
2. Set environment variables in `.env`.
3. Run the application: `python src/main.py`
